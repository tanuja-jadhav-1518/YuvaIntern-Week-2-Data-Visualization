# YuvaIntern – Week 2: Data Visualization and Insight Communication using R

## 📌 Project Overview
This project was completed as part of my Data Analyst Internship at YuvaIntern. The objective of Week 2 was to explore data visualization and communicate meaningful insights using R programming.

The project uses the Titanic dataset to analyze passenger information and survival patterns through different graphical visualizations.

## 🎯 Objectives
- Explore and understand the Titanic dataset.
- Create different types of visualizations using R.
- Analyze passenger survival based on gender, age, class, and embarkation port.
- Identify patterns and communicate insights using charts.

## 📊 Visualizations Created
- Passenger Survival Count
- Age Distribution
- Survival Rate by Gender
- Age vs Fare Scatter Plot
- Passenger Class Distribution
- Survival Rate by Passenger Class
- Survival Count by Gender
- Fare Distribution Histogram
- Age Distribution by Gender
- Survival Count by Passenger Class
- Fare Distribution by Passenger Class
- Survival Rate by Age Group
- Survival Rate by Embarkation Port
- Correlation Heatmap

## 🛠️ Tools & Technologies
- R Programming
- RStudio
- Titanic Dataset
- Data Visualization
- CSV Data

## 📈 Key Insights
- Survival patterns differed between male and female passengers.
- Passenger class played an important role in survival.
- Age and fare distributions helped understand passenger characteristics.
- Visualizations made trends and comparisons easier to understand.
